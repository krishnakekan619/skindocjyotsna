# Embedded fonts

`NotoSans-Regular.ttf` and `NotoSans-Bold.ttf` (unhinted) come from the Noto project:
<https://github.com/notofonts/notofonts.github.io/tree/main/fonts/NotoSans/unhinted/ttf>

They are licensed under the SIL Open Font License 1.1 (see `OFL.txt`), which allows embedding them in the app and in generated PDFs.

Noto Sans was chosen because it covers the Indian Rupee sign (₹, U+20B9) and looks the same on Windows and macOS. It is compiled into the app, so receipts never depend on the fonts installed on the machine.
